## Household practice
- Shared dinners are cooked to the **strictest shared constraint** (e.g. if one person is gluten‑free, shared dinners are gluten‑free; individual add‑ons handle the rest).
- Default shared carb base = something **everyone can eat** (e.g. potato/quinoa if someone can't have rice).
- Individual‑only items (a person's own bread, a kid's specific request) are theirs — never put an allergen into a shared dish to accommodate one person.
- Whole‑food bias across the board.
