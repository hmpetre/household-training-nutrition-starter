# Meal Library

Meals your household enjoys. Seed it with a handful you already love; the planner adds to it over time and learns your favorites. The planner reads this to pick recipes that maximize ingredient overlap, fit your prep style, and respect restrictions.

## How to tag a meal

```
### [Dish name]
- Type: [breakfast / lunch / dinner / snack]
- Components: [protein, carb base, veg, sauce/fats — the things you actually buy]
- Approx macros (per adult plate): [P / C / F grams], ~[kcal]   ← rough is fine; the planner refines portions
- Prep: [active minutes] · Equipment: [ ]
- Cost: [$ per serving, rough] · Servings: [ ]
- Restrictions it meets: [GF / DF / kid‑friendly / heart‑healthy …]
- Rating: [⭐ make again / 😐 ok / ❌ miss — never suggest again]
- Notes: [swaps, who loves it, "double the sauce"]
```
